## Problem Statement

Given an array** arr[] **consisting of only **0&rsquo;s and 1&rsquo;s**, return **count** of the maximum number of consecutive 1&rsquo;s or 0&rsquo;s present in the array. 

**Examples:**

**Input: **arr[] = [0, 1, 0, 1, 1, 1, 1]**
****Output: **4**
****Explanation: **The maximum number of consecutive 1&rsquo;s in the array is 4 from index 3-6.
**Input: **arr[] = [0, 0, 1, 0, 1, 0]**
****Output: **2**
****Explanation: **The maximum number of consecutive 0&rsquo;s in the array is 2 from index 0-1.
**Input: **arr[] = [0, 0, 0, 0]**
****Output: **4
**Explanation: **The maximum number of consecutive 0&rsquo;s in the array is 4.
**Constraints:
**1 &le; arr.size() &le; 105
0 &le; arr[i] &le; 1
